## Question

What is the rule that decides whether a thing is a skill, a reference document
reached by a pointer, or a startup instruction?

Nathan's hypothesis: several current skills are reference material rather than
invocable workflows, and should be pointers from AGENTS.md instead of listing
entries. The `gog-*` family is the clearest instance — 29 near-identical
per-service references behind one router.

Produce a rule that classifies any entry, testable against the current corpus,
and apply it to produce the per-entry disposition the destination requires.

Constraint from the global rules: startup instructions stay cross-project rules
and sharp routes; skills own workflows. This ticket sharpens that boundary into
something decidable.
