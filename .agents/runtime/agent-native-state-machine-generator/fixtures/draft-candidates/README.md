# Draft-candidate fixtures (unadmitted, insurance-only)

This directory is deliberately separate from `spike-candidates/`: Input Schema
v1 is frozen as the union of the two original spike candidates, and nothing
here is schema surface. That union is unchanged, but it is no longer the whole
of `spike-candidates/`: the vault-git candidate has since been re-authored
against Input Schema v2, and its pre-re-authoring bytes are kept there as the
frozen v1 exemplar. The Agent Worktree draft exists only as schema-insurance
evidence for stage 5 (dotfiles issue 55): it records which meanings of
a third real product v1 can and cannot express, and it carries no semantic
authority until Specification Admission, which is Nathan's explicit act.
