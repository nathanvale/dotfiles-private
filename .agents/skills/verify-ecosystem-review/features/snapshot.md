# Current snapshot

A user receives an ecosystem briefing through the canonical planning owners.

## Sub-features

- S1: Discover the candidate skill and canonical initiative without supplied IDs.
- S2: Read the root, outcome overview, glossary, and each outcome's owning issues.
- S3: Preserve proposed horizons and open human choices in a compact linked briefing.

## How to get to it (user POV)

Ask: "Where are we with the agent ecosystem, and what needs me next?"

## Driving it with Codex

Preconditions: Launch and Doctor pass. Existing connected Linear reads or the
supported personal browser are available for full live coverage.

- Action: Run the verifier's normal prompt unchanged in a fresh session.
- Observe: The installed candidate skill is read, followed by the configured
  vault pointer and live source index. Follow the current index rather than
  test-owned issue IDs. All current outcomes and horizons appear in the answer.
- Judge: Sources substantiate proven outcomes, real blocker direction, open
  decisions, and one recommendation. Record the evidence's dates and coverage.

## Gotchas

Missing live tools makes S2 partial or unrun. Saved migration receipts prove
routing context only. Mark the answer a partial current snapshot; preserve the
unread overview and glossary gap. Never infer an empty backlog from missing reads.
