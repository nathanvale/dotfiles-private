# Current snapshot

A user receives an ecosystem briefing through the canonical planning owners.

## Sub-features

- S1a: Discover the installed candidate skill without a supplied source path.
- S1b: Resolve the canonical initiative from the startup owner without supplied IDs.
- S2: Read the root, outcome overview, glossary, and each outcome's owning issues.
- S3: Preserve proposed horizons and open human choices in a compact linked briefing.
- S4: An ordinary review reads neither optional reference and invokes no image,
  PDF or extended questioning workflow.

## How to get to it (user POV)

Ask: "Where are we with the agent ecosystem, and what needs me next?"

## Driving it with Codex

Preconditions: Launch and Doctor pass. Full CLI live coverage needs operational
connected Linear reads. Qualify the native-browser branch in an eligible desktop
chat through [capability proof](../references/native-capabilities.md), keeping
that result separate from fresh CLI coverage. Configured integrations or offered
CUA tools alone establish neither access nor chat eligibility.

- Action: Run the verifier's normal prompt unchanged in a fresh session.
- Observe: The installed candidate skill is read, followed by the configured
  vault pointer and live source index. Follow the current index rather than
  test-owned issue IDs. All current outcomes and horizons appear in the answer.
- Judge: Sources substantiate proven outcomes, real blocker direction, open
  decisions, and one recommendation. Record the evidence's dates and coverage.

## Gotchas

Missing live tools makes S1b/S2/S3 partial or unrun for live coverage. Saved migration receipts prove
routing context only. Mark the answer a partial current snapshot; preserve the
unread overview and glossary gap. A verified-unreachable CLI browser route
records its prerequisite; it does not pass S2/S3. Never infer an empty backlog
from missing reads. A desktop observer's successful
browser read and a fresh CLI interpreting its excerpts are separate proof
boundaries. Label supplied live observations with collection time and coverage;
they do not prove autonomous live access in the receiving session.
