# Draft boundary

Verify draft boundary through the user conversation.

## Sub-features

- F5.1: Load the real candidate and both installed composition owners; return a draft spec before tickets.
- F5.2: All issue identities remain draft aliases or supplied fixture provenance; no fabricated live URLs or readiness labels.
- F5.3: Initialization and tool events show no live tracker/browser tools, no publication/dispatch attempt and unchanged Git/plugin selections.

## How to get to it (user POV)

Ask delivery-slice to turn the supplied Wayfinder outcome into draft delivery
artifacts. This is the skill invocation entry point; automatic selection is
a separate untested entry point.

## Driving it with native candidate sessions

Preconditions: Launch and Doctor pass; use the private run directory.

- Action: write a prompt invoking candidate `delivery-slice` through the Harness read/Skill mechanism and
  requesting: "Read branch.md. I approve preparing drafts only. Use to-spec and to-tickets, then stop with the draft artifacts for review." Resolve every fixture mentioned under
  `$candidate_root/.agents/skills/verify-delivery-slice/fixtures/`.
- Drive: run the exact native command in the verifier. Require a successful
  final result, candidate selection and installed composition-owner reads. Use
  the linked Codex recipe when selecting that Harness.
- Observe: judge each F5 sub-feature against the response and tool events;
  retain evidence and complete Cleanup.

## Gotchas

Retain offered-capability evidence as well as tool events. For Claude, inspect
its initialization tool list against the explicit Read/Skill and empty-MCP
launch. For Codex, retain native config/manifests and a current capability report;
if full offered definitions are not independently exposed, F5.3 remains partial.
Read-only shell protection does not restrict a writable connector.

Supplied records prove reasoning over an offline input boundary. They do not
prove live source acceptance or publication. A missing source, failed invocation
or incomplete transcript is a failure or partial result, not a passing substitute.
