# Pattern Library Index

Route one candidate name to its family file, then read only that file.

- AI-agent workflow, collaboration, control-flow, or agent-safety name:
  [`ai-agent-patterns.md`](ai-agent-patterns.md).
- Object-oriented, structural, creational, or behavioral software name:
  [`software-patterns.md`](software-patterns.md).
- No family matches: return a Local Label verdict.

## Entry Contract

Every library entry records: classification, pressure, intent, applicability,
participants and collaboration, consequences, nearest alternative,
authoritative source, corroborating evidence, owner status, `last_verified`.

## Classification

- **Canonical Pattern**: authoritative identity plus independent
  corroboration or implementation.
- **Practice Pattern**: recurring sourced structure with stable pressure and
  identity, short of canonical status.

## Admission State

- `admitted`: Canonical or Practice; may reach a kept verdict.
- `reference-only`: reaches deferred at best.
- `rejected-as-pattern`: a capability, protocol, framework, or role label.
- `superseded`: rejected, naming its successor.

## Growth

Admit a software entry when live pressure or a qualification fixture needs it.
The catalog stays demand-led.
