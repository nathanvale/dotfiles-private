# Hybrid recipe repairs

Start new and ordinary default steps with Agent Browser for the initial scoped
snapshot, controls, and observed in-page links. Keep a proven repaired step on
its recorded preferred adapter, then return subsequent ordinary steps to Agent
Browser. After a link or control changes the page, inspect the exact destination
before continuing. Do not use raw navigation or new-page helpers.

Use Chrome DevTools for bounded page JavaScript or Angular diagnosis,
Playwright for precise stateful forms, and Puppeteer for fixed actions. Switch
only the exact failed step.

For one failed step, repair only after an exact observation records no effect,
verified authority and custody, and an allowed ordered fallback. Record the
exact fallback adapter, passed assertion, effect, and evidence ID. Change only
that step's preferred adapter and fallback chain, increment the revision, and
clear acceptance. Resume later ordinary steps with Agent Browser.

An unknown Insert, Save, Delete, or Submit effect stops the recipe for
inspection. A supplied receipt is recorded evidence, not authenticated proof.
Only a fresh identity running the full mixed workflow in a real browser can
promote a candidate. A deterministic local-process fixture can prove contract
composition only; it cannot promote a recipe.

The v2 sidecar is `assets/recipe.json`; validate it with
`node scripts/recipe-contract.mjs --file RECIPE.json --script-root RECIPE_ROOT`.
`scriptRoot` is the root containing relative linked scripts. The helper exports
`validateRecipe`, `repairRecipe`, `verifyIndependentReceipt`, and
`migrateLegacyRecipe`; the first validates, repair returns a new candidate,
receipt verification returns a promoted recipe only for real-browser proof, and
migration returns a candidate without writing the legacy recipe.

Keep three hash records separate: accepted candidate recipe and linked-script
hashes; post-acceptance metadata hashes with explicit metadata-only provenance;
and promoted-destination path hashes. Any execution, script, adapter, or step
contract change creates a new candidate and needs fresh acceptance.
