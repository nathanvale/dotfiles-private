# Handover verification map

Use [the verification guide](../verify-handover.md) for launch, doctor, evidence
and cleanup. The surface is an unsent handover draft grounded in the recipient's
actual review pages and existing message. It has no separate app to install.

| Feature | Entry points and proof |
| --- | --- |
| [Preview links](preview-links.md) | Catalog, guide and exact example links; usable, missing, inaccessible, mismatched and local-only destinations |
| [Jira mapping](jira-map.md) | Requirement rows and examples; admitted coverage, held references and packaged-only states |
| [Draft and edit custody](draft-custody.md) | New draft or existing post; requested scope, preserved human edits, link inclusion and unsent boundary |

Run the changed feature through its real entry point. List unrun features as
unverified. Reuse prior evidence only with its actual input identities and limits.
