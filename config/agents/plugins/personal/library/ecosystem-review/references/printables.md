Australia/Melbourne, source scope and revision/time, evidence limits and usable
canonical pointers onto the printable. Supplied/offline or partial coverage
must be visible on the page. Keep Linear canonical; notes change no records.

routes, output custody and inspection requirements. Use
[the Inkwell reference](../assets/inkwell-style-reference.png) only for style:

session's designated artifact directory. Preserve originals. Add no renderer,
image runner, Linear client, planner or review-history store.

## A2 wall map

Preserve a supplied edition's composition when requested. The established
whole-project edition uses [this text-free layout](../assets/inkwell-a2-layout-reference.png):
a destination sign beside the header, a "THE FIRST USEFUL PATH" stage row,
"THE WHOLE PROJECT" illustrated outcome cards, then "ATTENTION", "SETTLED" and
"TODAY, CHOOSE ONE" strips. Refresh every label, status, decision and path from
the admitted sources. Adapt card count and path stages to that evidence;
the reference's empty boxes encode composition only. Label path ordering as
proposed where appropriate; arrows imply no native blocker without evidence.
Keep today's focus/win/waiting lines blank unless confirmed in conversation.
A horizon-grouped map remains available when requested. Use the established
whole-project edition for an unqualified regeneration of that edition.

For "regenerate our A2 Inkwell", produce ordinary landscape A2, 594 x 420 mm.
Preserve identifiable outcomes, proposed horizons/order, accepted decisions,
open questions and genuine blocker direction. Plan short readable text before
generation; never turn architectural links into delivery dependencies or freeze
the current number of outcomes in a reusable template. Link the current source
index/map and any material acceptance evidence. Include the evidence boundary
and one next-owner recommendation.

For an explicit "high resolution" request, inspect the image skill's supported
size routes and actual available tools first. Try a supported built-in route
when it exposes the requested native resolution. An API/CLI route requires the
image skill's explicit route authorization and existing credential custody;
"high resolution" alone does not authorize paid API fallback or a new key.
If that is the only available route, explain the prerequisite and ask only for
that missing route/access choice. Keep existing artwork when that choice is
pending. Do not silently switch models/routes, access secrets, upscale an old
image or claim a new high-resolution edition from ordinary output. An honest
unavailable-route result qualifies routing only, not artifact generation.

## A4 daily sheet

For "make my daily sheet", use confirmed conversational answers. Load
[daily focus](daily-focus.md) only when help choosing is also requested. A standalone
sheet request may produce a blank worksheet when answers are absent; ask only
if missing information prevents the requested result. Suggestions remain
proposals until chosen. Preserve the exact meaning and wording of answers;
resolve ambiguity before rendering rather than inventing text.

Create portrait A4, 210 x 297 mm. Render all prompts, borders and illustrations
in black Inkwell ink. Render only confirmed answers in blue felt-tip handwriting
style, with comfortable line spacing. Keep unknown fields visibly blank,
including dependency, parking and end-of-day answers. Use these fields in a
calm top-to-bottom reading order:

- Title: "ONE DAY. ONE USEFUL FINISH." and "Today in the ecosystem".
- Date, available time and epic/issue or canonical source pointer.
- "1 My one focus".
- "2 What I can point to when it is done".
- "3 My first action".
- "4 Waiting on a decision, evidence or access".
- "5 Parking space for everything else".
- "Before I stop", "What changed?" and "Where I resume".
- Footer: "Notes do not change Linear.", observation date and evidence scope.

Use short readable source labels plus real PDF link annotations when long URLs
would crowd the page. Verify their targets. A test sheet must visibly say
"Synthetic fixture answers"; never present those answers as Nathan's choice.

## Inspect and deliver

Generate the actual artwork and PDF, then reopen and render the final PDF.
Check each page's MediaBox dimensions and orientation; preserve aspect ratio
with print-safe margins and no cropping or resampling disguised as resolution.
Check every prompt, confirmed answer, unknown blank, date, source target and
status claim against the input. Inspect the render for color separation,
reading order, legibility, clipping, overlap and Inkwell fidelity. Correct
errors and re-render before claiming a pass. A prompt string alone proves no
visual behavior.

Record original raster pixel dimensions and embedded physical width/height;
effective ppi is pixels divided by embedded inches on each axis. Report actual
values, native generation route and any resampling. Page size is not a quality
claim. Separate digital inspection from an unperformed physical print proof.
Return concise links to the final PDF and preview, the date/evidence boundary,
actual resolution and any remaining limitation. Keep private planning content
and personal answers out of public source, fixtures and PR evidence.
