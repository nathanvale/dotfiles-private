# Friday preparation

Run every Friday at 16:00 Australia/Melbourne. Prepare the current Monday
through Sunday period for both portals, with work entries on Monday through
Friday only. A different explicitly requested period takes precedence.

1. Observe personal Chrome and reuse a matching task tab. Process the two
   portals independently through their canonical lists and references.
2. Verify Nathan's identity and the active contract. Use the same contract's
   submitted history to verify rate and row meaning, not to copy an old period.
3. Check the current conversation for explicit leave or hours exceptions and
   verify Victorian public holidays for this week against an official source.
   Do not inspect unrelated private calendars or messages. A normal five-day
   draft is authorised unless an exception is known. If one is detected, ask
   one targeted question and prepare the unaffected portal if safe.
4. Skip an already submitted matching week and report it. Reuse a saved draft
   matching the pattern. Fill absent normal rows. Preserve conflicting rows
   and ask about the exact delta rather than overwriting them.
5. Save, reopen from the canonical list and verify all seven dates, entries,
   notes, contract, rate and total. Complete each screenshot evidence set and
   hashes before asking for submission.
6. Show the actual screenshots inline: "Your drafts for [dates] are ready:
   Iterate 5 days; Monash 40 hours. Submit both?" If only one is ready, name it
   and the other portal's concrete blocker. Do not claim an unsaved draft.
7. On approval, submit only the named current evidence sets once per portal,
   including expected confirmations. Prove the final portal states. A partial
   success never authorises retrying the other portal's uncertain submission.

Keep an approval handoff tab open when the Harness supports it. Store private
evidence under `~/.local/state/timesheets/<period>/<portal>/`. A scheduler wakeup
is not proof of portal completion. Re-read live portal state on resumption.
If Chrome, the credential wrapper or a required login is unavailable, report
one concise cause and repair action instead of repeatedly requesting sign-in.
The Mac and Codex must be available for this local automation to execute.
